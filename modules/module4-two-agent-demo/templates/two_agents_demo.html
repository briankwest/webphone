Module 4: Coordinate agent-to-agent calling across browser windows

📋 Setup Instructions

⚠️ Important: Browser Limitation

The SignalWire SDK cannot run multiple instances in the same browser context. You must use:

  • Two different browsers (e.g., Chrome + Firefox), OR
  • One regular window + one incognito/private window

Steps to Run the Demo:

  1. Open Alice: to open Alice in this browser
  2. Open Bob: and open in:
    • A different browser, OR
    • An incognito/private window (Ctrl+Shift+N / Cmd+Shift+N)
  3. Make Calls: Use either window to call the other agent

Direct URLs:

Alice: http://localhost:5004/login?agent=alice
Bob: http://localhost:5004/login?agent=bob
