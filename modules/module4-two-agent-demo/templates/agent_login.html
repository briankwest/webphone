🎓 Learning Point:

Module 4 demonstrates agent-to-agent calling. Each agent has a unique reference ID that SignalWire uses for authentication and routing. When you log in, the server generates a token specific to your agent identity. This enables features like agent-to-agent calling and personalized call routing.

Try this: Open two browser windows (or use regular + incognito mode) and log in as different agents. You'll see how each session maintains its own identity!
