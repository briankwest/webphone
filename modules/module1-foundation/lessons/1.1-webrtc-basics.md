## 📚 What is WebRTC?

WebRTC (Web Real-Time Communication) is a technology that enables:
- **Video calling** directly in web browsers
- **Audio calling** without plugins or downloads
- **Data sharing** between browsers in real-time
- **Peer-to-peer connections** for low latency

### The WebRTC Triangle

```
    Browser A                    Browser B
        |                            |
        |    1. Exchange Info        |
        |<-------------------------->|
        |     (via Signaling)        |
        |                            |
        |    2. Direct P2P           |
        |===========================>|
        |     Media Stream           |
```

## 🔑 Key WebRTC Concepts

### 1. MediaStream
- Access to camera and microphone
- Managed by the browser's getUserMedia API
- Requires user permission

### 2. RTCPeerConnection
- The core of WebRTC
- Handles the actual media transmission
- Manages codecs, network traversal, security

### 3. Signaling
- **Not part of WebRTC spec!**
- Exchange of connection information
- This is where SignalWire comes in

## 🌟 Why SignalWire?

WebRTC gives us the technology, but we still need:

### 1. **Signaling Server**
```javascript
// Without SignalWire (complex!)
// You need to:
// - Build WebSocket server
// - Handle offer/answer exchange  
// - Manage ICE candidates
// - Track user presence

// With SignalWire (simple!)
client = await SignalWire.SignalWire({ token });
call = await client.dial({ to: destination });
```

### 2. **TURN/STUN Servers**
- **STUN**: Discovers your public IP
- **TURN**: Relays traffic when direct connection fails
- SignalWire provides both automatically

### 3. **PSTN Connectivity**
- Call regular phone numbers
- Receive calls from phones
- Bridge web and traditional telephony

## 🔄 The Connection Flow

### Step 1: Authentication
```
Browser → Flask Server: "I need access"
Flask → SignalWire API: "Generate token for user1"
SignalWire → Flask: "Here's the token"
Flask → Browser: "Use this token"
```

### Step 2: Connection
```
Browser → SignalWire: "Connect me with this token"
SignalWire: "✓ You're authenticated as user1"
SignalWire → Browser: "Connected! Ready for calls"
```

### Step 3: Making a Call
```
Browser: "Call +1234567890"
SignalWire: "Setting up call..."
SignalWire → PSTN: "Calling number..."
PSTN → Recipient: *ring ring*
Recipient: *answers*
SignalWire → Browser: "Call connected!"
```

## 🏗️ SignalWire Architecture

### Call Fabric
SignalWire's Call Fabric is their WebRTC infrastructure:

```
┌─────────────────────────────────────┐
│         Call Fabric Cloud           │
├─────────────────────────────────────┤
│  • Authentication Service           │
│  • Signaling Servers               │
│  • TURN/STUN Servers              │
│  • Media Servers                   │
│  • PSTN Gateways                  │
└─────────────────────────────────────┘
            ↑           ↑
            │           │
     [Browser A]    [Browser B]
```

## 💡 Real-World Analogy

Think of WebRTC like making a phone call:

1. **Phone Number** = SignalWire Reference/Token
2. **Phone Company** = SignalWire 
3. **Dial Tone** = WebSocket Connection
4. **Dialing** = Signaling
5. **Conversation** = Media Stream

## 🎮 Interactive Demo

Open your browser console and try:

```javascript

  .then(devices => {
    devices.forEach(device => {
      console.log(`${device.kind}: ${device.label}`);
    });
  });
```
